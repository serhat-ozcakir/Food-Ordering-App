## 📖 Overview

Bestell App is a modern food ordering web application inspired by Lieferando. Users can browse meals, add them to a shopping cart, adjust quantities and complete a simulated order.

The project focuses on clean JavaScript architecture, responsive layouts and a user-friendly ordering experience.

---

## ✨ Features

- 🍽️ Dynamic menu rendering
- 🛒 Shopping cart
- ➕ Increase & decrease quantity
- ❌ Remove meals from cart
- 💰 Automatic price calculation
- 📦 Order summary
- 🎉 Order confirmation
- 📱 Responsive design
- 📌 Sticky shopping cart
- ⚡ Fast user interaction

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Responsive Design

---

## 🚀 Main Functionality

- Display restaurant information
- Dynamic meal rendering
- Add meals to the shopping cart
- Increase or decrease meal quantity
- Remove meals from the cart
- Automatic subtotal calculation
- Responsive shopping cart
- Complete simulated checkout process
